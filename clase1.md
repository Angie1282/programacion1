# CLASE1 

Una aplicación se compone por 5 elementos:
1. Código
2. Servidor
3. Base de datos
4. Interfaz de usuario
5. Servicios externos

##  1. Código
Contiene los procedimientos que describen el comportamiento de la aplicación 

## 2. Servidor
Máquina física o virtual donde se aloja la aplicación ejecutada

## 3. Base de datos
Sistema de almacenamiento de estados en la aplicación

## 4. Interfaz de usuario
Sistema donde el usuario genera los eventos que serán procesados por la aplicación

## 5. Servicios externos
Cualquier sistema que no se implementa directamente en la aplicación como sistema de almacenamiento de archivos, servicio de e-mail
