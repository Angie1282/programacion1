# Ejercicios de Python 🐍

Este repositorio reúne ejercicios de programación en Python que voy resolviendo mientras aprendo el lenguaje.

## Objetivo

Practicar y reforzar los fundamentos de Python con ejercicios cortos, como:

- Variables y tipos de datos
- Condicionales y ciclos
- Funciones
- Listas, tuplas y diccionarios
- Manejo de archivos y errores

## Cómo ejecutar los ejercicios

1. Tener instalado [Python 3](https://www.python.org/downloads/).
2. Clonar el repositorio o descargar los archivos.
3. Ejecutar cualquier ejercicio desde la terminal:

   python nombre_del_ejercicio.py
